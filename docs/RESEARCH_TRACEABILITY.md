# Research-to-Artefact Traceability

| Research / business-plan finding | Artefact response |
|---|---|
| Return cannot be used as a proxy for adoption | Eligible orders and reusable issues are recorded separately from issue/return events |
| A returned container is not automatically reusable | `Returned`, `Washed` and `Inspected` are separate states |
| Non-return is commercially material | `Lost` is an explicit state; outstanding stock and return time are shown |
| Environmental break-even is system-specific | The sustainability module compares verified cycles with named study thresholds and avoids a generic carbon-saving output |
| QR already exists in competitor systems | QR is treated as an enabling control layer, not the innovation claim |
| Dense networks can be operationally advantageous | Site-baseline and reverse-logistics gates precede scale decisions |
| Published pricing does not equal EcoLoop pricing | Sheffield benchmark economics are separated from the EcoLoop model |
| EcoLoop revenue logic is fixed + completed-circulation based | Fixed site-management and variable completed-circulation charges are explicit revenue inputs |
| Evidence existence does not prove viability | Each gate has readiness and performance status |
| Pilot evidence should determine thresholds | The site model derives minimum uptake/return/inspection tests where the entered economics make them mathematically solvable |
