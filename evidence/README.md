# Evidence pack

This folder contains selected research records that support the EcoLoop Pack business plan and artefact.

The evidence is intentionally separated into:

- peer-reviewed / official evidence;
- institutional and programme benchmarks;
- current public procurement references;
- management planning assumptions;
- derived calculations.

No file in this folder should be interpreted as observed EcoLoop pilot performance unless explicitly labelled as observed. The project did not run a live commercial pilot.

The full assessed report, ethics documentation and supervisor correspondence are submitted separately through the university system and are not published here.
